# A4 8ページ小冊子 面付けツール

A4用紙1枚を8分割し、中央に1本だけ切れ目を入れて作るA7相当の小冊子用の面付けWebアプリです。

## 主な機能

- 8ページPDFを一括読み込み
- PDF / PNG / JPGをページごとに個別指定・差し替え
- 横書き・左開き（標準）
  - 上段（180°回転）: 5 / 4 / 3 / 2
  - 下段（通常）: 6 / 7 / 8 / 1
- 縦書き・右開きにも切り替え可能
  - 上段（180°回転）: 2 / 3 / 4 / 5
  - 下段（通常）: 1 / 8 / 7 / 6
- 折り線・切り線の表示／非表示
- A4横1ページPDFとして出力
- ファイルはブラウザ内だけで処理（サーバーへのアップロードなし）

## 使い方

1. `index.html` をブラウザで開きます。
2. 8ページPDFを一括読み込みするか、各ページへPDF/PNG/JPGを指定します。
3. 面付けプレビューを確認します。
4. 「A4面付けPDFを作成」を押します。
5. 出力PDFをA4横・100%（実際のサイズ）で片面印刷します。

## 注意

このアプリは `pdf-lib` と `PDF.js` をCDNから読み込みます。初回利用時を含め、インターネット接続が必要です。

印刷時にプリンター側の「用紙に合わせる」「縮小」「拡大」が有効だと、折り位置がずれることがあります。100% / Actual size を推奨します。

## GitHub Pagesで使う場合

このフォルダ内の `index.html`, `styles.css`, `app.js` をリポジトリ直下に置き、GitHub Pagesを有効化すればそのまま利用できます。

## テスト用ファイル

- `sample_8pages.pdf`: 1〜8のページ番号と上下方向を明示した8ページPDF
- `sample_imposed_reference.pdf`: 上記を横書き・左開きで面付けした確認用PDF

まず `sample_8pages.pdf` を一括読み込みし、アプリから出力したPDFが `sample_imposed_reference.pdf` と同じ並びになることを確認できます。
